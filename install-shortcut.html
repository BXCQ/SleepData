睡眠数据自动上传

在 iPhone 上打开本页，点下方按钮即可跳转到「快捷指令」导入。
站点：blog.ybyq.wang

打开快捷指令并导入 下载 .shortcut 文件

请用 Safari / iPhone 打开。电脑浏览器无法直接装到手机快捷指令里。

导入后怎么用
  1. 首次运行允许读取「健康」睡眠数据。
  2. 填写 API 地址：https://blog.ybyq.wang/usr/plugins/SleepData/shortcut-api.php
  3. 填写插件里的访问令牌。
  4. 在「自动化」里设每天早上运行本快捷指令。
若提示无法导入 / 未签名
  1. 设置 → 快捷指令 → 打开「高级」→ 允许未信任的快捷指令。
  2. 或先点「下载 .shortcut 文件」，到「文件」App 中打开，选择用快捷指令打开。
  3. 仍失败时，按 SHORTCUTS.md 手动搭建（约 5 分钟）。
