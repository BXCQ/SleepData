睡眠数据自动上传

不走 GitHub 在线导入（国内常失败 / 未签名会被拒）。
本页已内嵌快捷指令文件，请按下面步骤安装。

② 备用：尝试系统导入（可能失败）

请用 iPhone Safari 打开本页。

下载后怎么打开
  1. 1打开系统「文件」App
  2. 2找到 SleepData-AutoUpload.shortcut（一般在「下载」）
  3. 3点文件 → 用「快捷指令」打开 / 分享到快捷指令
  4. 4若提示未信任：设置 → 快捷指令 → 高级 → 允许未信任的快捷指令
导入后填写
  1. API：https://blog.ybyq.wang/usr/plugins/SleepData/shortcut-api.php
  2. 访问令牌：插件后台配置
  3. 允许读取健康「睡眠」数据

服务器尚未合并时，可先装好快捷指令；合并部署 shortcut-api.php 后再运行上传。
