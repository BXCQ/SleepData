睡眠数据自动上传

不依赖博客是否已合并代码。
快捷指令文件从 GitHub 拉取；导入后 API 仍指向 blog.ybyq.wang。

打开快捷指令并导入 下载 .shortcut 文件

请用 iPhone Safari 打开本页（可 AirDrop 此 HTML 到手机，用「文件」→ Safari 打开）。

导入后填写
  1. API：https://blog.ybyq.wang/usr/plugins/SleepData/shortcut-api.php
  2. 访问令牌：插件后台配置的令牌
  3. 允许读取「健康」睡眠数据

注意：若服务器还没合并 PR，shortcut-api.php 还不存在，导入快捷指令可以先完成；接口部署后再运行上传。

若提示无法导入
  1. 设置 → 快捷指令 → 高级 → 允许未信任的快捷指令
  2. 或先下载 .shortcut，用「文件」App 打开
